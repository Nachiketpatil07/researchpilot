# ResearchPilot API

Backend of [ResearchPilot](https://github.com/Nachiketpatil07/researchpilot), an agentic RAG
research assistant: hybrid retrieval, cross-encoder reranking, a LangGraph agent with web
fallback, and groundedness checks.

This Space runs as a **read-only demo** over five RAG/agent papers, with per-IP rate limits.
API docs: `/docs`. Source, setup and evaluation results: see the GitHub repo.
